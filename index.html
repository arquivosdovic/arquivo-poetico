Conteúdo Literário

  • Separe os termos por espaço pra combinar — todos precisam aparecer.
  • Use aspas pra buscar a frase exata: "beira do mar".
  • Prefixe com - pra excluir: -rascunho ou -2023.
  • Por padrão a busca olha título, ano, etiqueta, pessoa e livros vinculados — não usa data de escrita/publicação (pra isso, veja o filtro de data logo abaixo).
  • Pra restringir a um atributo específico, prefixe o termo com o nome dele e dois-pontos: titulo:, texto:, etiqueta:, pessoa:, nota:, livro:, parte:, secao:.
  • Exemplos: pessoa:Dalton, secao:"Fragmentos do Fim", -etiqueta:rascunho.

Elementos e Respiros

Estrutura do Livro

Gera um JSON flat com os itens marcados.

Escolha um livro acima pra ver a árvore completa, com a sequência de cada item — útil pra confirmar se a reordenação automática ficou certa.

Exportação

Gera um JSON só com o que você escolher — útil pra mandar um recorte específico pra uma IA processar, sem o resto do arquivo.

Preencha só o que souber. Meses totalmente cobertos pelo intervalo aparecem mesmo sem dia cadastrado.

Quer revisar/substituir textos sensíveis antes de exportar? Abra o JSON em Versões Alternativas.

Procurando o export aninhado completo (Livro → Parte → Seção → Poema/Prosa, sem filtro, pra mandar pra uma IA)? Agora é o botão "Exportar Aninhado" no cabeçalho da página.

Backups automáticos — o app tira um retrato do acervo sozinho a cada poucas horas de uso e guarda os últimos 10 aqui no navegador (IndexedDB). Não substitui o "Baixar JSON" acima (essa é a única cópia que sai do navegador), mas ajuda a recuperar uma versão de horas/dias atrás se algo der errado numa edição.
